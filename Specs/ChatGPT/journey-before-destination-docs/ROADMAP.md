# Roadmap
## Journey Before Destination

## Phase 1: App Shell

Goal:
Create the basic React app structure.

Includes:
- Vite setup
- React Router
- Page routes
- Layout component
- Navigation
- Placeholder pages

## Phase 2: Static Data

Goal:
Load local JSON data and display it.

Includes:
- orders.json
- books.json
- prompts.json
- characters.json
- Render Order cards
- Render RadiantDex list
- Render Character detail pages

## Phase 3: Fake User Profile

Goal:
Create a local user profile.

Includes:
- Onboarding flow
- Select Order
- Select books read
- Save to localStorage
- Display profile data on dashboard

## Phase 4: Dashboard

Goal:
Make the dashboard feel like the home base.

Includes:
- Today's prompt
- Order card
- Active oath card
- Reading progress
- Recently viewed character

## Phase 5: Oaths

Goal:
Build the core personal development feature.

Includes:
- Create oath
- Add actions
- Mark actions complete
- Edit/archive oath
- Save to localStorage

## Phase 6: Journal

Goal:
Build private reflection.

Includes:
- Prompt response entries
- Freeform entries
- Link entries to prompts/oaths
- Save to localStorage

## Phase 7: RadiantDex MVP

Goal:
Make the RadiantDex useful and fun.

Includes:
- Search
- Filter by Order
- Filter by book
- Favorites
- Character details
- Simple spoiler filtering by book

## Phase 8: Polish MVP

Goal:
Make it feel finished enough to use.

Includes:
- Empty states
- Error states
- Better copy
- Basic responsive layout
- Visual styling
- Data cleanup

## Future Phase: Progression

Includes:
- XP
- Ideal ranks
- Achievements
- Streaks

## Future Phase: Integrations

Includes:
- Coppermind API exploration
- Supabase
- Real auth
- Roshar map
