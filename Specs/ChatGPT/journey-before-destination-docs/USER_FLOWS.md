# User Flows
## Journey Before Destination

## First-Time User Flow

```txt
Start Page
↓
Begin Journey
↓
Onboarding
↓
Choose Radiant Order or Skip
↓
Select Books Read
↓
Select Books To Read
↓
Create First Oath
↓
Dashboard
```

## Returning User Flow

```txt
Open App
↓
Dashboard
↓
Read Today's Prompt
↓
Choose Action:
  - Respond in Journal
  - Complete Oath Action
  - Browse RadiantDex
  - Update Reading Progress
↓
Leave
```

## Choose Order Flow

```txt
Onboarding/Profile
↓
View Orders
↓
Select Order
↓
Save
↓
Dashboard updates with Order card and Order prompts
```

If the user skips Order selection:

```txt
Dashboard
↓
Reminder Card:
"Choose your Order to unlock daily prompts."
```

## Create Oath Flow

```txt
Oaths Page
↓
Create New Oath
↓
Enter Oath Title
↓
Add Actions
↓
Save
↓
Oath appears on Dashboard
```

## Complete Oath Action Flow

```txt
Dashboard or Oaths Page
↓
View Active Oath
↓
Check off Action
↓
Progress updates
```

## Journal Flow

```txt
Dashboard Prompt
↓
Respond to Prompt
↓
Write Entry
↓
Save
↓
Entry appears in Journal
```

Freeform flow:

```txt
Journal Page
↓
New Freeform Entry
↓
Write Entry
↓
Optional Tag: Oath, Character, Prompt
↓
Save
```

## RadiantDex Flow

```txt
RadiantDex
↓
Search or Filter
↓
Select Character
↓
View Character Page
↓
Favorite Character
↓
Return to List or Dashboard
```

## Reading Progress Flow

```txt
Profile or Onboarding
↓
Select Books Read
↓
Select Books To Read
↓
Save
↓
RadiantDex spoiler filtering updates
```
